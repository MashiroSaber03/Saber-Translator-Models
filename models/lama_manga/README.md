# LaMA Manga

漫画版 LaMA 文字背景修复模型

- 模型包：[`lama_manga.zip`](https://github.com/MashiroSaber03/Saber-Translator-Models/releases/download/model-files-v2/lama_manga.zip)
- 解压到应用的 `models/` 目录，保留包内 `lama-manga/` 路径；也可在应用“设置 → 模型管理”中自动安装。
- ZIP 大小：204333160 字节
- ZIP SHA-256：`b43c46265d287c2c5f51c21522ab32d4d20b415d29b291869deac3a5c09e73bb`
