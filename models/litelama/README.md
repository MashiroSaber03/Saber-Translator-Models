# LiteLaMA

LiteLaMA 文字背景修复模型

- 模型包：[`litelama.zip`](https://github.com/MashiroSaber03/Saber-Translator-Models/releases/download/model-files-v2/litelama.zip)
- 解压到应用的 `models/` 目录，保留包内 `lama/` 路径；也可在应用“设置 → 模型管理”中自动安装。
- ZIP 大小：496800528 字节
- ZIP SHA-256：`8fa06a2b806d447cc898aa2168dc3a071fcdedffcd110497660487a710017893`
