# PaddleOCR-VL-1.6

PaddleOCR-VL-1.6 视觉语言识别模型

- 模型包：[`paddleocr_vl.zip`](https://github.com/MashiroSaber03/Saber-Translator-Models/releases/download/model-files-v2/paddleocr_vl.zip)
- 解压到应用的 `models/` 目录，保留包内 `paddleocr_vl_1_6/` 路径；也可在应用“设置 → 模型管理”中自动安装。
- ZIP 大小：1930278193 字节
- ZIP SHA-256：`d49401a4ef9b11e3e00fe64d28d12e7de7707c98530651b1ca9eaa0f5bac9430`
