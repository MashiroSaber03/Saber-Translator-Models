# YSGYolo 文本检测

YSGYolo 检测模型，也用于辅助检测

- 模型包：[`detector_yolo.zip`](https://github.com/MashiroSaber03/Saber-Translator-Models/releases/download/model-files-v2/detector_yolo.zip)
- 解压到应用的 `models/` 目录，保留包内 `yolo/` 路径；也可在应用“设置 → 模型管理”中自动安装。
- ZIP 大小：16534159 字节
- ZIP SHA-256：`50073ba43a03f27e3fc029bde65075cfd592b95a921cf614abc9c67a20a79e38`
